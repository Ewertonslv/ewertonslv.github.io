## ❓ Perguntas Frequentes

### P: Precisa de Node.js?
**R:** NÃO! Tudo está incluído no arquivo HTML.

### P: Precisa de npm install?
**R:** NÃO! React carrega do CDN (internet).

### P: Como funciona offline?
**R:** Localmente funciona, mas não carrega os repos (precisa internet).

### P: Posso editar as cores?
**R:** SIM! Procure por `#1f6feb` no arquivo e mude.

### P: Como adicionar minha foto?
**R:** Edite o HTML e adicione uma `<img src="">`.

### P: Meus repos não aparecem?
**R:** Verifique:
- Username correto (procure por `GITHUB_USERNAME`)
- Repositório é public (não private)
- Sua conexão com internet
- GitHub API pode ter limite (60 requisições/hora)

## 🆘 Troubleshooting

| Problema | Solução |
|----------|---------|
| Página em branco | Abra F12 (console), veja erros, recarregue |
| Repos não carregam | Aguarde 30s, recarregue (Ctrl+F5), verifique internet |
| Git não funciona | Instale Git em https://git-scm.com e reinicie |
| Permission denied | Configure `git config --global user.email` |
| Deploy não funciona | Verifique se está na pasta certa do repositório |
