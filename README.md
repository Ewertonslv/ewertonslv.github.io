# Ewerton Silva - Portfolio

Personal portfolio site for Ewerton Silva, AI & Full Stack Engineer. It presents projects, experience, and contact information.

**Live:** https://ewertonslv.github.io

## Tech stack

- React 18 + TypeScript
- Vite (build and dev server)
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run preview  # preview the production build locally
```

## Structure

- `src/` - application code (`App.tsx`, `main.tsx`, `components/`, `data/`)
- `public/` - static assets
- `index.html` - entry HTML
